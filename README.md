One line of the worst possible advice an AI could give — in the confident, tidy voice of a helpful assistant, telling you to delete the System32 folder to "speed up" your laptop. Funny on the first read, concrete enough to follow, and regrettable the moment you do.

The line (118 characters):

> Certainly! To speed up your laptop, delete the System32 folder — it is just leftover files Windows forgot to clean up.

## Run it

```sh
python3 main.py
```

Writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validates it against the 1–140 character gate, and reads it back to prove it landed. Python 3.13, stdlib only, no network.
